# Proyecto TP5 Programación 2

## Propósito principal
Este archivo documenta los cambios y el estado general del proyecto. Está ubicado en la raíz, fuera de las carpetas principales `tailwind/` y `uikit/`.

## Estructura del proyecto
- `tailwind/`: carpeta con versión del proyecto usando Tailwind CSS.
- `uikit/`: carpeta con versión del proyecto usando UIkit.

## Registro de cambios
- Aquí se anotarán los cambios que el usuario vaya haciendo en el proyecto.

## Cambios recientes
- Archivo inicial creado para seguimiento de cambios.
- [uikit/catalogo.html] Se incorporó un footer similar al de Tailwind, con secciones de tienda, info y legales, enlaces estilizados y íconos de redes.

- [uikit/detalle_united.html] Se ajustaron los márgenes laterales del contenido principal para que quede más aireado y parecido al diseño de Tailwind.
- [uikit/detalle_united.html] Se agregó un botón de volver al catálogo, ubicado en la barra superior del título, con estilo de flecha y efecto hover.
